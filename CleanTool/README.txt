QUICK START:
------------
1. TO RUN THE APPLICATION:
   Double-click "Run_VideoGen_Studio.bat".
   The backend engine will start and your native desktop studio window
   will open automatically at: http://127.0.0.1:8765

2. TO BUILD STANDALONE EXECUTABLE & PORTABLE ZIP:
   Double-click "Build_Standalone_EXE.bat".
   This compiles everything into a self-contained portable package in:
   dist\VideoGenStudio\VideoGenStudio.exe
   and dist\VideoGenStudio-Windows-Portable.zip (no Python required on target PC).

KEY FEATURES:
-------------
- AI Visual Director (Groq Primary with Multi-Key Pool & Fallback).
- Universal Stock Footage Engine across 1,000+ niches (Pexels + Pixabay).
- Persistent Anti-Repetition Engine (never duplicates clips in same or across videos).
- CapCut Kinetic Subtitles with word-level bouncing and animation presets.
- 1-Click CapCut Timeline Draft Exporter.
- Automated Storage Cleaner (keeps hard drive light & auto-prunes raw cache).
- Intel QuickSync (QSV) Hardware Accelerated Rendering.

OUTPUT FOLDERS:
---------------
- Rendered Videos:  data\output\
- Saved Thumbnails: data\thumbnails\
- YouTube SEO Data: data\seo\
- Sound Effects:    data\sfx\
- Active Settings:  data\settings.json
